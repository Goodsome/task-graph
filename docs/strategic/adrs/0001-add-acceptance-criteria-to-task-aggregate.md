# ADR 0001: 在 Task 聚合根中增加 BDD 验收标准

## 状态 (Status)
已通过 (Accepted)

## 背景 (Context)
系统的北极星目标是构建一个由 AI Agent 驱动的任务编排与问题追踪系统。为了实现研发全链路的闭环管理，不仅需要管理任务的生命周期，还需要确保任务的质量。

目前，`Task` 聚合根缺少明确的质量评估标准。通过引入结构化的验收标准（Acceptance Criteria），系统可以：
1. **增强 Agent 的规划能力**：使 AI 明确了解任务完成的界限。
2. **自动生成测试用例**：作为元数据，支持未来自动生成单元测试、集成测试及皮下测试（Subcutaneous Testing）。

## 决策 (Decision)
在 `Planning` 限界上下文的 `Task` 聚合根中增加 `acceptance_criteria` 字段。

### 详细规范：
1. **领域模型**：每一条验收标准应被定义为一个独立的值对象（Value Object），能够结构化地表达 BDD 规则（如包含 Given/When/Then 等语义属性）。
2. **语言风格**：强制支持 BDD (Behavior-Driven Development) 风格，以便后续解析。
3. **元数据存储**：这些标准作为 `Task` 的核心元数据持久化。
4. **向后兼容性**：在项目早期阶段，此变更不强制要求对历史数据进行迁移（假设系统仍处于初期迭代）。
5. **战术自治**：具体的集合类型实现（如 List 或 Set）与数据解析细节由 `Planning` 上下文主理人在战术设计阶段决定。

## 后果 (Consequences)
### 正面影响：
*   提升了任务的可测试性与可验证性。
*   为未来的 AI 自动化工具提供了结构化的输入。
*   强化了 `Planning` 核心域的业务厚度。

### 负面影响：
*   增加了 `Task` 聚合根的存储体积。
*   在创建/更新 Task 时增加了录入成本（需要 BDD 格式化）。
